# ECS panel transport preflight v1

This preflight covers the proposed QNM circle with 16 complex-ball panels
and transports the coarse spin-two ECS initializer from \(r=45\) to \(r=4\)
using order-16 Taylor steps with rigorous Cauchy tails.

The rectangular dependency width grows past \(10^{16}\).  The method is
therefore fail-closed for Evans work.  A true affine Lohner/Taylor-model or
Riccati/Grassmannian rail is required.
