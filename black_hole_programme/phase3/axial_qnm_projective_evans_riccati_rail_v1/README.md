# Projective Evans/Riccati rail v1

This package certifies the first refined-panel radial step of the
phase-factored outgoing spin-two line in the projective chart

```text
q = (partial_x P_out) / P_out.
```

The complete frequency-dependent outgoing phase is kept outside
`P_out`.  The transported state is the correlated triple
`(q, q_tau, q_omega)`.  The initial reduced-amplitude ball excludes zero,
and one validated Taylor/affine-remainder step reaches
`r=899/20` from `r=45`.

Dependency tags: `LOCAL-ALGEBRAIC`, `REDUCED-MODE`.

This is a one-endpoint, one-radial-panel certificate.  It does not construct
the horizon line, a two-sided mismatch, a contour root count, or a QNM/EP2.
