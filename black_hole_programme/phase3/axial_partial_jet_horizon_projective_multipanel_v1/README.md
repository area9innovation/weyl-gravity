This package records two bounded correlation-preserving continuations of the
phase-factored horizon column.

The full shared-frequency complex-pivot chart reaches five order-12
micro-panels before the interval pivot inverse refuses with
`IVTAY_KRAWCZYK_UNCERTIFIED`. Its local exponential tail is below
\(3\times10^{-24}\), so this is a chart inversion enclosure failure rather
than a local truncation failure.

The alternate midpoint/Lohner chart removes only the exact rational Taylor
centre of the pivot and retains all shared frequency dependence in the
affine state. That bounded attempt exceeded 240 seconds without emitting a
completed-panel record and was terminated. It is a throughput shortfall,
not a passed transport.

Transport to \(r=4\), \(K_H\), \(T_+\), H4, and global scattering remain
fail closed.
