# Transport-free outgoing-defect preflight

This package separates two logically different results.

Tier A proves the exact, basis-covariant reduction

\[
O=T_-^\dagger G_-T_- - H_{\rm out}
  =T_+^\dagger G_+T_+,
\qquad
\det O=\det G_+\,|\det T_+|^2.
\]

It traces all signs from the boundary contract and all bases from the Gram
and incoming-connection certificates. The determinant test remains open
because the certified incoming theorem contains only the determinant and
invertibility of \(T_-\), not its full typed \(3\times3\) entries.

Tier B removes a packaging overconstraint. Exact infinity-frame existence,
future-horizon solutions, conserved radial current, wave-packet traces and
trace-limit interchange define the abstract \(T_+\) trace and prove Stokes
without evaluating its entries. Since \(T_-\) is invertible, the raw
one-sided map

\[
x\longmapsto
\left(T_+T_-^{-1}x,\;T_-^{-1}x\right)
\]

is an injective pseudo-isometry from \(G_-\) to
\(G_+\oplus H_{\rm out}\). This does not establish the rank of \(T_+\).

The included \(\omega=1/2\) determinant is classified only as `OBSERVED`.
Its \(T_-\) comes from an explicitly `UNVALIDATED-NUMERIC` point preview,
with the required infinity amplitude conjugation applied. The certificate
also carries an explicit missing-object ledger for the full typed
\(T_-\), explicit \(T_+\), and common-\(J\) frame data.
