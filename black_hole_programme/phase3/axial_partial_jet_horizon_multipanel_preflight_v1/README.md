# Axial partial-jet horizon multipanel preflight v1

This package continues the phase-factored spin-two and Levelt-regularized
spin-one horizon column across geometric panels on the first frequency
child.

It propagates the correlated four-state base/tangent system in
`IvTaylor4_omega tensor dual_tau` arithmetic and, independently, the direct
regular-frame twelve-state column. The two routes continue to overlap.

The calculation refuses after 27 panels, at shell 6 panel 3, because the
cumulative state hull exceeds the declared width threshold. The local
order-24 exponential remainder is still below \(6\times10^{-27}\), so the
failure is cumulative interval dependency rather than endpoint
singularity or local Taylor truncation.

No nonlinear projective, Riccati, QR, or midpoint-preconditioned
reconditioning is used. Transport to \(r=4\), \(K_H\), \(T_+\), H4, and
global scattering remain fail closed.
