# Axial outgoing population on a real-frequency cell

For Schwarzschild \(M=1\), axial \(\ell=2\), and every
\[
0.49995\le\omega\le0.50005,
\]
validated scalar reflection bounds and exact boundary dévissage prove
\[
T_+(\omega)\in GL(3,\mathbb C).
\]

Consequently the complete three-dimensional outgoing trace space is
populated throughout the cell.  The transport-free outgoing pullback is
nondegenerate with inertia \((1,2,0)\) for \(\alpha_{\rm W}>0\).

Standard holomorphic Jost dependence then implies that \(T_+\) is invertible
off a locally finite positive-real exceptional set.  Its multiplication
operator is a bounded \(L^2\) isomorphism on the certified cell and has
dense range on every compact positive-frequency band.

This result does not prove that the exceptional set is empty, provide
explicit \(T_+\) entries, give a uniform full-axis inverse bound, or
establish full time-domain stability.
