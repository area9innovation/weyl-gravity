# Axial QNM ECS tangent initializer v1

This package differentiates the contracted ECS scalar Volterra problem in
the exact reduced projective deformation direction.  It produces uniform
balls for the intrinsic tangent value and derivative at \(r=45\).

The result is in the canonical reduced cocycle gauge.  The analytic endpoint
gauge needed to identify the manuscript factor-frame entry \(b\), and hence
\(b/a\), remains open.
