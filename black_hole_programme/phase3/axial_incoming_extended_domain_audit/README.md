# Extended audit of the analytic incoming connection

This package strengthens the analytic \(T_-\) theorem in three directions
and corrects a proposed fourth:

1. \(\lvert\det T_-\rvert\ge\sqrt{5/2}\) on
   \(\omega\in[1/2,3/4]\).
2. The exact endpoint construction, \(T_-\) invertibility, and incoming Gram
   inertia extend to every real \(\omega>0\); \(\omega=0\) remains a separate
   collision problem.
3. In an exact factor-adapted basis, the incoming Gram splits orthogonally
   into the spin-two Regge--Wheeler extension
   \(\ker\pi_x=\operatorname{span}\{EI,RI\}\), of inertia \((1,1,0)\), and
   a spin-one quotient lift \(SI\), of inertia \((0,1,0)\).
4. With the repository convention \(\exp(+i\omega t)\), positivity excludes
   **lower**-half-plane zeros, which would grow in time.  It does not exclude
   upper-half-plane damped quasinormal zeros.  The proposed no-UHP theorem
   is therefore rejected on convention grounds.

The points \(\omega=i/4,i/2,i\) are certified singularities of the chosen
Frobenius/reconstruction frames.  Whether they are simultaneously genuine
reduced Evans zeros remains open.
