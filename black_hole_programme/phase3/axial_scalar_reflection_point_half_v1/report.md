# Validated pointwise scalar reflection

have nonzero outgoing reflection:
\[
|A_{{\rm out},1}|>0.4592873681,\qquad
|A_{{\rm out},2}|>0.0733170840.
\]

different Taylor geometries.  This is enough to exclude a diagonal zero in
the intrinsic triangular outgoing RW/RW/spin-one connection.  A separate
typed bridge may combine these scalar bounds with the exact endpoint frame

time-domain stability.
