# Shared reading shell and paper-led introduction — 8 September 2026

The site can support this design with its existing static Python renderer,
structured editorial data, CSS and JavaScript. The diagnosed problem was
separate navigation/layout implementations, not missing browser capabilities.
The implementation centralizes the header and native perspective menu across
Introduction, Questions, Theory journeys/Atlas, Papers, Dictionary and the
positivity case. Specialized atlas tools retain their own data layout.

Perspective checkboxes now live in a compact disclosure menu showing the
current selection. It supports multiple selections, Compare all four, keyboard
operation, Escape and outside-click dismissal. Selection stays in local
storage and links. Shared pages explain that their term definitions change;
the atlas itself does not acquire unreviewed audience rewrites.

The introduction is now a programme-wide adaptation of Papers 99 and 98,
with eight aligned sections at all four perspectives: purpose, assumptions,
the 576-cell map, case studies, bounded results, open gates, evidence and
exploration. Each section records reviewed source IDs. The wave example is
one case within this introduction rather than its organizing theme. The
historical papers remain unmodified, and the current full-export rejection
continues to override their earlier affirmative transfer language. No theorem
or lifecycle has been promoted.

ACA and RCA are expanded in the general definitions and have visible “Stands
for” labels. Abbreviation records now require the full expansion in their
general definition. The introduction expands artificial intelligence at first
general use. Static dictionary crosslinks connect unambiguous terms inside
explanatory paragraphs, excluding self-links and repeated targets in one
paragraph. Deliberate related links retain connections to ambiguous terms.
Existing controls preserve the perspective while following these links.

Validation includes source/hash and structure checks, independent tests of
crosslink escaping and target selection, abbreviation-gate mutations, menu
interaction on all seven main routes, eight-section audience parity, mobile
bounds, dictionary navigation, no-JavaScript reading and legacy atlas links.
Screenshots were inspected at desktop and mobile widths. Exact commands,
times and content hashes are in ../receipts/unified-reading-shell-v1.json.
Tier 3 is not applicable: these are editorial and interface changes with no
mathematical input or scientific lifecycle change. Semantic equivalence of
prose remains an editorial judgment, not something these tests certify.
