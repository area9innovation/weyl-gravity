# Clickable tooltip titles

The term title at the top of each dictionary tooltip is now a native link to
its standalone page. It preserves the perspective(s) displayed by that tooltip,
including the edition of the surrounding paragraph. The existing comparison
link still opens all four accounts. Native anchors support keyboard activation
and opening another tab. Definitions, sources and scientific claims are unchanged.

Both dictionary browser suites pass, including direct title navigation,
perspective preservation and existing hover/focus/tap/comparison behavior.
The deterministic site verifier checks generated outputs and their manifest.
The companion receipt records commands, timings and hashes. Tier 0 syntax and
whitespace checks, Tier 1 browser regressions and Tier 2 generated-site checks
pass. Tier 3 is unnecessary: no mathematical inputs, shared algebra, lifecycle
promotion or release changed. No scientific dependency tag or claim is promoted.
