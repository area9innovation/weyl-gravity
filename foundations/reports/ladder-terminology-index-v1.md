# Strength-ladder terminology index — 8 September 2026

The previous inventory aggregated the ladder with other atlas prose and
omitted displayed `open`, `separation`, `candidate_upper_bound` and
`establishes_if_formalized` fields. These are now included. A focused index
covers the six rendered stages and preserves each match's stage, field,
source string and character offsets.

The first curated pass indexes 52 concepts and four status labels. Examples
include PRA (Primitive Recursive Arithmetic), Galerkin nesting, Fast-Cauchy
names, coefficient-to-distribution comparison, test-function topology and
slab globalization. Five entries link to related dictionary explanations;
51 are explicitly marked Definition pending. This is a vocabulary index,
not 56 completed definitions or proof of semantic completeness.

The alphabetical index appears directly on the ladder. Stage links retain the
selected perspective and focus the target stage. A browser regression exposed
that atlas URL normalization initially discarded the new stage parameter on
reload. The v2 renderer now preserves a valid ladder stage while that view is
active, and drops it when another view is selected.

The index is generated independently of scientific grades. It neither changes
historical ladder statuses nor implies that selecting General rewrites the
technical ladder into a general-reader account. The full-export correction
remains visible. No scientific certificate or lifecycle is promoted.

Validation independently checks original source strings and offsets, verifies
omitted-field coverage, and compares every indexed text with the rendered DOM.
Browser checks exercise jumps, reload, audience-preserving dictionary links
and mobile index bounds. Exact commands, timings and hashes are in
../receipts/ladder-terminology-index-v1.json. The affected site verification
chain is run; Tier 3 is unnecessary because no mathematical input or claim
changes. Future work is four-perspective explanations for the pending terms.
