\section{Independent central residual-rank check}

The command
\begin{verbatim}
python3 symbolic/verify_conformal_residual_rank53_independent.py
\end{verbatim}
uses only the Python standard library.  It constructs the integral spin-two
$\mathfrak{sl}_2\oplus\mathfrak{sl}_2$ action on
\[
 \operatorname{Sym}^2\bigl((2,0)\oplus(0,2)\bigr),
 \qquad 55=15+25+15,
\]
and obtains exact block ranks
\[
 53=14+25+14.
\]
The two exact kernel vectors are the chiral binary-quartic singlets
\[
 e_0e_4-4e_1e_3+3e_2^2.
\]
Ranks are computed over two prime fields.  Since modular rank is a
characteristic-zero lower bound and the two displayed independent exact
kernel vectors give the complementary upper bound, the characteristic-zero
rank is exactly $53$.

This independent check is intentionally narrow.  It does not replace the
one-particle $290\to1311\to3657$ absolute window, full Chevalley--Eilenberg
nilpotency, BV--BFV transfer or covariant causal certificates.

\section{Clean release and reproduction}

From the repository project directory, the isolated release audit is
\begin{verbatim}
python3 symbolic/audit_conformal_publication_release.py \
  --tree-ish HEAD \
  --receipt conformal-publication-release-audit.json
\end{verbatim}
The selected tree-ish must already contain the four TeX sources and four
PDFs.  Untracked or merely staged working-tree files are deliberately
ignored, so this command is a post-commit release gate rather than a
development-tree preview.
It uses \verb|git archive| rather than the development working tree, verifies
that all four TeX entrypoints, all four publication PDFs and every recursively
active TeX input are tracked in the selected tree, checks the generated
Nullstellensatz input, builds each document to reference stability, and runs the independent
rank, provenance and proof-ledger checks.  The JSON receipt is a CI artifact,
not an authoritative mathematical input.

The focused clean-release audit complements, rather than replaces, the full
theorem rail
\begin{verbatim}
python3 symbolic/verify_conformal_paper_free.py --reproduce --timeout 1800
\end{verbatim}
and the content manifest check
\begin{verbatim}
python3 symbolic/update_conformal_paper_snapshot.py --check
\end{verbatim}

The release audit is fail-closed on missing tracked entrypoints, unresolved
TeX inputs, stale generated TeX, failed independent checks, failed stabilized
builds, undefined references and stale manifests.  The archival equation
labels remain available for referee auditability even though Papers A and B
are now the primary reading entrypoints.
