# Twist-balanced exceptional `ell=1` resonance obstruction

Dependency tags: `LOCAL-ALGEBRAIC`, `REDUCED-MODE`.

The axial exceptional dipole

```text
omega_e^2=4/3,
(h_t,h_x,q_t,q_x)=(0,1,0,-3)
```

has negative constant-lapse Taub form. A standard twist velocity on the same
real `m=0` axis has the opposite sign. With `A=0`, the exact balance

```text
B^2=(8/3)e^2
```

makes all background-stabilizer moment maps vanish.

This common-zero tangent nevertheless fails the complete second-order
equation. The direct four-dimensional positive-positive self-source of the
exceptional mode has a polar `L=2,k=0` component at

```text
Omega=2*omega_e,
Omega^2=16/3=6-2/3,
```

which is exactly the polar fourth-order target shell. In row order
`(E00,E01,E11,Etr,E0a,E1a,Etf,M)` its complex source is

```text
(23/3,0,49/27,79/27,46*i*sqrt(3)/27,0,-22/9,1).
```

The target matrix has rank `2`, while adjoining this source raises the rank to
`3`. Two exact adjoint-kernel rows pair with it as

```text
-2/3,
 4/3.
```

Therefore no second-order correction exists. Twist self-products have
generalized zero frequency and twist--extra cross-products have frequency
`omega_e`; neither can modify the `2*omega_e` channel. This is a dynamical
resonant obstruction after the global Taub charges have already canceled.

The result is one sharp mixed no-go, not the full exceptional dipole cone.
Polar exceptional input or another opposite-sign oscillator could in principle
cancel both resonant pairings and remains the next test.
