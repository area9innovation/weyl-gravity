# Exceptional `ell=1` same-frequency isolation

Dependency tags: `LOCAL-ALGEBRAIC`, `REDUCED-MODE`.

`ell>=2` extra primary obeys

```text

```

and the lowest Einstein primary obeys

```text
omega_-^2=lambda-sqrt(2lambda) >= 6-2sqrt(3) > 4/3.
```

`(14/3)^2-12=88/9>0`, and the branch is increasing for `lambda>=6`.

and twist blocks are generalized zero-frequency data.

`ell>=1` `omega_e` eigenspace is exactly the two-parity block already covered
by the all-`m` STF obstruction theorem.  An unclassified `ell=0` target mode
is not needed for this conclusion: `0 x 0` produces only `L=0`, `0 x 1` only
`L=1`, and an `L=2` cross term would require an `ell=2` partner, whose
frequency is separated.

Consequently no same-frequency nonexceptional `k=0` augmentation can cancel
the positive-positive `L=2,Omega=2omega_e` defect.  The pure exceptional
`ell=1,k=0` second-order no-go is frozen.  Pairs of unequal frequencies whose
sum is `2omega_e`, and pairs of opposite nonzero momenta, remain open.
