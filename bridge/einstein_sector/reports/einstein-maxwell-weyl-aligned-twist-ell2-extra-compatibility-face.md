# Aligned twist--generic-extra compatibility face

The completed homogeneous/twist source matrix does not force the mixed
global--extra cone to the origin.  Put an arbitrary nonzero four-component
generic extra-primary amplitude on the positive-frequency
`ell=2,m=0,k=0` harmonic, and align both twist vectors with the same axis.
The unique `V1 tensor V2 -> V2` resonant intertwiner then vanishes because

```text
<1,0;2,0|2,0> = 0.
```

The branchwise rank-three `a,b,d` chains force `a=b=d=0`.  In orthonormal
harmonics the extra occupation is

```text
X = 1296|x_a1|^2 + (208/3)|x_a2|^2
    + 22464|x_p1|^2 + 12288|x_p2|^2,
```

and the exact balance `B_z^2=(2/3)X` makes `mu_H=0`.  The extra `m=0`
state has zero rotational moment, `A cross B=0`, and `k=0`, so all five
stabilizer moment maps vanish.  The explicit witness `x_a1=1`,
`B_z=12*sqrt(6)` has zero remainder.

This certifies a nonzero simultaneous stabilizer and completed bounded-
resonance common-zero face.  It is not yet a bounded or smooth-secular
second-order extension: nonresonant polynomial cross channels and their
correction-class-specific right inverses remain to be assembled.  The full
off-axis zero locus, other momenta and causal corrections remain open.
