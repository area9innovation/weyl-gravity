# Exceptional arbitrary-\(k\) all-\(m\) locked incidence

## Result

The previously certified axisymmetric \(k\)-by-\(2k\) difference functional
has a unique all-\(m\) completion.  In Cartesian harmonic carriers, write the
exceptional axial and polar dipoles as complex vectors \(x_{\rm ax}\) and
\(x_{\rm pol}\) in \(V_1\), and write the contributing transported polar-extra
\(e_2\) quadrupole as a complex symmetric trace-free matrix \(Y\) in \(V_2\).
Then

\[
 R_{\rm ax}(k)=-\frac{768}{5}Y\overline{x_{\rm ax}},
 \qquad
 R_{\rm pol}(k)=-\frac{864}{5}Y\overline{x_{\rm pol}} .
\]

The other six branch-parity maps vanish identically.

This is forced, rather than guessed, by an exact intertwiner calculation.  The
rotation-generator linear system has 45 unknowns and rank 44, so

\[
 \dim\operatorname{Hom}_{SO(3)}(V_1\otimes V_2,V_1)=1.
\]

The canonical generator of this one-dimensional space is \(B(x,Y)=Yx\).
For \(x=e_z\) and
\(Y=y\,\operatorname{diag}(-\tfrac12,-\tfrac12,1)\), it returns \(y e_z\);
therefore the imported direct \(m=0\) coefficients fix the displayed
normalizations.  The same nonzero axis fixture proves that each of the six
zero coefficients multiplies the zero intertwiner, so their all-\(m\) maps
vanish.

## Exact zero set

On this sharply declared locked two-fibre carrier, the difference functional
vanishes if and only if

\[
 \overline{x_{\rm ax}},\overline{x_{\rm pol}}\in\ker Y .
\]

Its complete rank stratification is:

- \(\operatorname{rank}Y=3\): both exceptional vectors vanish;
- \(\operatorname{rank}Y=2\): both vectors lie in the conjugate of the same
  one-complex-dimensional kernel;
- \(\operatorname{rank}Y=1\): both vectors lie in the conjugate of the same
  two-complex-dimensional kernel;
- \(Y=0\): both exceptional vectors are arbitrary.

The complex rank-one stratum is nonempty because
\(Y=vv^T\) is trace free when \(v^Tv=0\).  It is absent from the nonzero
real-coefficient STF slice, but positive-frequency coefficients are complex,
so it cannot be discarded from the certified carrier.

## Boundary

This closes the all-\(m\) tensor assembly and cancellation geometry only for
the locked difference row.  It does not yet intersect this incidence variety
with the five stabilizer moment maps or with arbitrary-\(k\) homogeneous,
twist, exceptional-self, and other generic-wave rows that can share a
bounded-solvability ledger.  The enlarged bounded cone and every larger
multiple-\(\lvert k\rvert\) union therefore remain open.
