# Global plus axial ell=2 all-m bounded cone

The bounded opposite-sign cone survives for every axial `m=-2,...,2`.
Because the homogeneous `a,b,d` block is rotationally scalar, each
time-polynomial shell coefficient is an `SO(3)` intertwiner `V_2 -> V_2`.
Schur's lemma promotes the direct `m=0` pivots to the identity on the full
multiplet, so nonzero Einstein-minus data force `a=b=d=0` without allowing
cross-`m` cancellation.

The earlier all-m wave theorem is bounded more strongly than originally
stated.  At zero-frequency axial `L=1`, the rotation constraints put the
source in the form `(S0,S1,S0,S1)`, and the constant correction
`(S0/2,-S1/2,0,0)` is an exact right inverse.  No Jordan growth is needed.

The complete declared global cone is the union of the wave-free standard
branch `(c,d,W_x,A)` and a nonzero wave branch with `a=b=d=Q_e=B=0`, arbitrary
`(c,W_x,A)`, and axial Einstein-minus/extra densities satisfying all four
`H,J_a` equations.  Polar waves, other harmonics and nonzero momenta remain
open.
