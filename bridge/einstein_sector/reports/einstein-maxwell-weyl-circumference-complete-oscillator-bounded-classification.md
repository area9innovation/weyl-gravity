# Complete circumference oscillator column

The exact circle-radius family separates zero momentum from travelling modes.
Writing `R^2=1+eta*c`, every certified oscillator has

```text
omega_R^2=k^2/R^2+m_branch^2.
```

At `k=0`, the frequency is stationary.  Differentiating covariant circle
indices gives only an ordinary same-frequency correction, so the
`c`-times-wave source is bounded-removable.  The complete `ell=2` extra block
provides a coefficient-level all-row fixture.

At `k!=0`,

```text
partial_eta omega|_0=-c*k^2/(2*omega),
partial_eta exp(-i*omega_eta*t)|_0
  =i*c*k^2*t*exp(-i*omega*t)/(2*omega).
```

The exact radius family therefore supplies a smooth secular correction, but
not a bounded one.  The action-derived current is nonradical on every
standard branch and every extra multiplicity block, so the corresponding
shell source has a nonzero adjoint pairing for every nonzero mode when
`c*k!=0`.  This is a resonance functional `R_(j,a)`, not a positive-degree
source functional `P_(j,r)`.

For an arbitrary finite harmonic sum, the complete `c` cross column is
bounded-compatible exactly when `c=0` or the oscillator support is contained
in `k=0`.  The complete bounded cone, causal transport, all-orders
integration, residual descent, observables and quantum theory remain open.
