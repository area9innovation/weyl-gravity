# Nonzero-momentum exceptional ell=1 solution cofiber

## Result

For every real nonzero compact momentum (k=2\pi n/L), the local-gauge-reduced
Weyl--Maxwell target has two simple exceptional shells in each parity,

\[
\omega^2-k^2=4,
\qquad
\omega^2-k^2=\frac43.
\]

The first shell is exactly the Einstein--Maxwell image under the certified
polynomial all-row chain map.  The second is a one-dimensional solution
cofiber.  The statement is tensor-producted with the real ell=1 (SO(3))
multiplicity and keeps axial and polar parity separate.

## Exact witnesses

The certificate records polynomial gauge-quotient representatives, shellwise
rank minors, and the CRT projectors in the spectral variable
(s=\omega^2-k^2).  It checks directly that the standard representatives lie
in both source and target kernels, whereas the extra representatives lie only
in the target kernels.  In the polar gauge slice it additionally verifies the
exact quotient relation

\[
v_{\rm source}-v_{\rm gauge}=2v_{\rm target,std}
\quad\bmod\quad \omega^2-k^2-4,
\]

so the standard target shell is proved to be the image rather than merely an
isospectral branch.  No division by (k), (omega), a wave factor, or a helicity
projector is used.

For the displayed polynomial representatives, the action-derived Hermitian
current has diagonal weights

\[
G_{\rm ax}=\operatorname{diag}
\bigl(4(k^2+4),\,4(3k^2+4)\bigr),
\qquad
G_{\rm pol}=\operatorname{diag}
\bigl(4,\,4(3k^2+4)\bigr),
\]

in standard/extra order.  Standard and extra shells are orthogonal.  Thus the
two-parity extra cofiber is nonradical and positive for real nonzero (k).

## Boundary

This is a same-background `REDUCED-MODE` theorem.  The all-row coefficient map
is already certified, but this result does not reconstruct the harmonic tables
as one natural support-local tensor-bundle morphism.  It also does not perform
the finite residual endpoint quotient or make causal, particle,
observational, cross-background, or quantum claims.
