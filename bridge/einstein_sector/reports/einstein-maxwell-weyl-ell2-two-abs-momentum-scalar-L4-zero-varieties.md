# Five scalar-internal L4 amplitude zero varieties

Five of the twelve `L=4` physical circumference fibres have one input copy
per parity and one target-adjoint component per parity.  On these fibres the
highest-spin projection is multiplication

`Sym^4(C^2) x Sym^4(C^2) -> Sym^8(C^2)`.

Because the binary-form polynomial ring has no zero divisors, the complete
all-`m` resonance zero set admits an exact case split.  Each fibre has exactly
four irreducible complex components: the plane where the first momentum fibre
vanishes, the plane where the second vanishes, and two mixed sheets on which
the polar amplitude in each momentum fibre is a fixed scalar multiple of its
axial amplitude.  The two scalar ratios solve the displayed parity equations;
their squared discriminant is exactly positive on all five real coefficient
embeddings, so all ten mixed sheets have real representatives.

This is the first irreducible decomposition of the factorized amplitude
system.  It proves that branch-basis obstruction does not extend to a pure
all-amplitude no-go even on these `L=4` backgrounds.  The other sixteen
cross-fibre varieties, same-fibre quadratic sources, five Taub maps, complete
tangent cone, smooth-secular and causal correction classes remain open.
