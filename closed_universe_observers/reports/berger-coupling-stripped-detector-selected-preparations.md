# Coupling-stripped detector-selected preparations

Dependency tags: `LOCAL-ALGEBRAIC`, `LORENTZIAN-CAUSAL`.

The advanced detector covector is linear in the declared nonzero emitter
coupling.  We therefore write

```text
v_a = g_a tilde_v_a,
tilde_u_a = (-tilde_p_a, L_a tilde_q_a),
L_a = Delta_2^co-closed + m_a^2,
```

and hold `tilde_u_a` fixed in the formal coupling expansion.  Its energy is
strictly positive.  Consequently

```text
M_aa^(1) = g_a tilde_E_a,
det M^(1) = g_0 g_1 tilde_E_0 tilde_E_1 != 0,
Delta M_ab,c^(3) carries g_b g_c^2.
```

This is scalar factorization, not adaptive response normalization.  Harmonic
preparation coefficients, massive images and recoil intervals remain open.
