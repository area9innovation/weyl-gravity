# Quantitative detector rod chart

The explicit global rods oscillate by `a(t)=cos(sqrt(58)(t-t_a)/6)`.  On each
detector window `a(t)>=1-29/82944`.  Choosing both radial profile radii to be
`1/128` yields `|y|^2<1/10000` under the exact inverse rod map, so the support
lies uniquely on the detector-connected `y0>0` branch of `S3`.  The Jacobian
`8 c a(t)^3` is nonzero.  This removes the formerly free radius parameter;
harmonic quadrature and Green evaluation remain open.
